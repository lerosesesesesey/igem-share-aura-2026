<Section id="overview" title="Software overview" kicker="01">

Software supports signal processing, calibration, documentation, and delivery of an alert. The critical path should be able to run locally at the parlour; a cloud connection must not be required to recognise or display a warning.

</Section>

<Section id="analysis" title="Analysis scripts" kicker="02">

<Section id="reader-app" title="Alert interface" kicker="04">

A minimal mobile-friendly interface can receive a device result, show which cow or milk line needs attention, and archive the timestamp and sensor status. Privacy and data ownership remain farm-controlled; no cloud requirement is assumed for the first version.

<Callout variant="note" title="Scope">
  Alert delivery is part of the concept, but the interface and decision threshold still require validation with users and reference measurements.
</Callout>

</Section>
